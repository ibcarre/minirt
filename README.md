# miniRT

A ray tracing engine written in C as part of the 42 curriculum.

## Features

- Ray tracing and intersection calculations between rays and geometric primitives.
- Scene object management and property handling.
- Lighting with multiple colored light sources.
- Shadow computation and anti-aliasing.
- Multithreaded rendering to distribute computations across multiple threads.

## Technologies

- C
- 3D geometry and vector mathematics
- Multithreading and concurrent programming

## Build and Run

```bash
make
./miniRT scenes/example.rt
```

## Usage

The program takes a scene file describing the elements to render. Refer to the example scenes and the scene format specifications provided in the repository.
